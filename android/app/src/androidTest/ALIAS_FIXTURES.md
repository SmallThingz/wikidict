# Compiled redirect test fixtures

These assets are instrumentation/JVM test inputs and are not shipped in release or performance APKs.

- `compiled-aliases.wikblb` and `compiled-alias-targets.wikblb` are the synthetic outputs of the core repository's `tools/reader_integration_test.zig::writeAliasFixture`, qualified against core revision `a50b6e3`. They cover four case-sensitive Bulgarian redirect spellings and a synthetic two-edge chain; definitions are synthetic.
- `alias-edges.wikblb` and `alias-rhymes.wikblb` are synthetic DAL1/DPR2 records covering cycles, self edges, missing targets, feature namespaces, unsupported target namespaces, and a feature-to-main-alias edge with no incoming language selection. All eight expected read outcomes were independently replayed through the current core C ABI, whose SHA-256 is `8bda2090d8db63c1a460f68241dc731609aec0992c896370563eb97c7a6dd202`.
- `bom-identities.wikblb` is a synthetic DPR2 fixture with a leading-U+FEFF English heading and word title. The same core C ABI independently verified both exact identities; its canonical heading basename is `93eaaad295c94f5b52113b9032a16310e01a620e52557e4db08d826914bef869.wikblb`.
- `arabic-visual.wikblb` is an unchanged two-record excerpt (`-هُم`, `آ`) from the completed Arabic Wiktionary 2026-10-01 language blob headed `العربية`. It is a portrait/RTL visual fixture, not a full dictionary. Its SHA-256 is `e88272c938178f2a74a9c5ab0f96608bb6cb56d3524f27ae98d25c16545a016e`. Source and attribution: https://ar.wiktionary.org/ and https://dumps.wikimedia.org/arwiktionary/20261001/ ; the Wikimedia text licences below apply.
- `af-aliases.wikblb.xz` is the complete 88-record redirect sidecar from the Afrikaans Wiktionary 2026-10-01 dump, compiled by the core corpus builder. Its leading-U+FEFF source title is deliberately preserved. Source: https://dumps.wikimedia.org/afwiktionary/20261001/ .
