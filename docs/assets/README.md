# Visual design references

`language-globe-reference.png` is the original raster reference.
`language-globe.svg` is the existing editable vector draft. Its text uses
system fonts, so glyph appearance depends on the fonts installed by the viewer.

These files preserve the design work that previously sat untracked in the
repository root. The raster was originally named
`ChatGPT Image Sep 24, 2026, 03_49_27 PM.png`; the vector was named
`wikidict-language-globe.svg`. Both were moved without changing their bytes.
